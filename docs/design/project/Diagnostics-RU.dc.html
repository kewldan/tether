На телефоне выключена отладка по USB
Телефон не открывает интерфейс adb. Откройте Настройки › Система › Для разработчиков и включите Отладку по USB. Нет такого раздела? Сначала 7 раз нажмите на Номер сборки.
Режим USB — «Только зарядка»
В этом режиме некоторые телефоны скрывают отладку. Откройте шторку уведомлений, нажмите Зарядка устройства через USB и выберите Передача файлов.
