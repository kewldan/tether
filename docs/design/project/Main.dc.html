Design system · v0.1

Tether

A quiet, dense desktop GUI for Android Debug Bridge. Working name for adb-gui.
Tokens are shadcn-compatible CSS variables (Tailwind v4 @theme inline). Dark is the primary theme; light is tuned separately, not inverted. Switch this board's theme in Tweaks.

07 · Decisions

Rules of the house

One accent, one job
Iris marks the single next action on a view (primary button), the current location (nav marker, selected tab) and links. Never decoration, never status. If two primaries compete, one becomes secondary.
Density by default
4 px grid, 32 px rows, 13 px body. Compact mode drops rows to 28 and controls to 26 without changing type size. Panels split by 1 px borders; elevation only for things that float.
Status is earned
Green/amber/red/blue appear only for real state: device status, task result, log level. Always dot + label or icon + text. Destructive red is the only status hue allowed on a button.
